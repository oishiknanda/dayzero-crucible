These face detection, face mesh, iris, and face-description model assets are from
`@vladmandic/human` 3.3.6. The Human library is distributed under the MIT
License; see `LICENSE-human.txt`. Model credits are documented by the upstream
project at https://github.com/vladmandic/human/wiki/Models.

The app loads these files from its own origin. Webcam frames and face descriptors
are processed in browser memory and are not sent to the server.
